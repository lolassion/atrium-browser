# Atrium Browser

A fast, private browser in the Atrium style. Built on Chromium.

**Download:** [AtriumBrowser-Setup.exe](https://github.com/lolassion/atrium-browser/releases/latest/download/AtriumBrowser-Setup.exe) (installer) or [AtriumBrowser-Portable.exe](https://github.com/lolassion/atrium-browser/releases/latest/download/AtriumBrowser-Portable.exe) (no install) · [Website](https://lolassion.github.io/atrium/browser.html)

## What it does

- **Shields:** blocks ads and trackers (EasyList, EasyPrivacy, Ghostery lists), hides cookie banners, per-site toggle.
- **HTTPS-only:** every connection is upgraded; you're warned before anything loads unencrypted.
- **Global Privacy Control**, no click-tracking pings, no WebRTC IP leaks, identifies as standard Chrome.
- **Sandboxed tabs**, permission prompts for camera, microphone, location and notifications, cross-site cookie access always denied.
- Private windows, bookmarks, session restore, downloads, find in page, DuckDuckGo by default.

## Good to know

- Windows SmartScreen warns on first launch because the app isn't code-signed yet: choose **More info → Run anyway**.
- There's no auto-update yet. Install new releases from this page to get Chromium security fixes.
- DRM-protected video (Netflix, Spotify, Disney+) doesn't play.
